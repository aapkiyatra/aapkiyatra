# Aapki Yatra Tour & Travel

Responsive static travel website with Aapki Yatra branding, journeys from Shimla, itinerary dialogs, destination filters, a manual enquiry builder, founder information and social links.

## Run locally

Run `python3 -m http.server 8080` and open http://localhost:8080.

## Deploy

GitHub Pages publishes the repository root from the `main` branch. Live site: https://aapkiyatra.github.io/aapkiyatra/ No build or package installation is needed.

## Content and enquiries

Package itineraries are suggestions; prices and inclusions need a personalised quote. The enquiry form prepares a message for the visitor to copy into Instagram or Facebook; it does not submit or store enquiries. Verified Google review text and business contact details are still needed; the current review section links to the supplied Google business listing.

The logo asset was prepared from the supplied logo reference. Photos are served locally from Unsplash downloads. The layout follows the supplied travel-site screenshots while retaining Aapki Yatra content and logo colours.
